# testing-ground
A safe space to dump random assortments of code and demos without the mental overhead of creating yet another repo.

Each individual folder within this repo is a distinct project. These projects are often completely unrelated, so context and content that applies to one folder doesn't nessecarily apply to other folders. 

If you are submitting code to this repo that represents a new project, then please feel free to create a new top-level folder to contain all your project code and assets. If you are working on a specific project, please limit your changes to only the relevant folder for that projevt.
